# CSET 105 Final Project 2: Quiz

## Project Info
This second part of the final project for CSET 105 involves creating a quiz within an interactive webpage.

## Features
- Displays a question & list of answers from an array of objects depending on the question number
- Activates submit button on selecting an answer
- Proceeds to next question on submit
- Calculates final score on quiz completion
- Allows user to restart quiz

For the second part of the final project, see [Final Project 1](https://github.com/ADRabert/CSET105Final1).
